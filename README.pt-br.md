## 🚀 Projetos em Destaque

### 🥊 [Luva de Combate com TinyML](https://github.com/lucaasporto/luva-combate-tinyml)
* Este projeto é um dispositivo vestível capaz de identificar automaticamente golpes de boxe usando Inteligência Artificial embarcada em um Arduino Nano 33 BLE Sense[cite: 1]. 
* O sistema lê dados do acelerômetro e giroscópio para inferir os movimentos e disponibiliza os resultados via Bluetooth Low Energy (BLE) em tempo real[cite: 1].

### 🔋 [BioMon - Multímetro de 12 Canais](https://github.com/lucaasporto/multimetro-12-canais)
* BioMon é um sistema de monitoramento contínuo escalável e de baixo custo para aquisição de bioeletricidade, focado especificamente em células a combustível microbianas[cite: 2]. 
* Alimentado por um ESP32, ele lê 12 canais simultâneos na escala de milivolts e envia automaticamente os lotes processados para um documento do Google Sheets via Wi-Fi[cite: 2].

### ♨️ [Simulador de Micro-ondas com FreeRTOS](https://github.com/lucaasporto/simulador-micro-ondas)
* Uma aplicação embarcada simulando um forno de micro-ondas para aplicar conceitos de tarefas concorrentes, sincronização, filas e interrupções[cite: 3].
* O sistema foi desenvolvido utilizando um microcontrolador PIC24FJ128GA010 e o sistema operacional de tempo real FreeRTOS, com o circuito eletrônico e execução totalmente simulados no Proteus[cite: 3].

### ♟️ [TiX - Tabuleiro Inteligente de Xadrez](https://github.com/lucaasporto/xadrez-1d)
* O TiX é um tabuleiro físico e inteligente para Xadrez 1D que registra automaticamente as partidas e as transmite via Bluetooth para um computador[cite: 4].
* Ele identifica as peças usando leituras analógicas através de resistores e integra-se com uma aplicação Python construída com Pygame para verificar movimentos legais e registrar o jogo[cite: 4].

### 🎟️ [LUNI - Plataforma de Gestão de Ingressos](https://github.com/lucaasporto/banco-de-dados-gestao-de-ingressos)
* LUNI é um sistema de banco de dados projetado para uma plataforma de venda de ingressos[cite: 5]. 
* Desenvolvido em Python com conexão MySQL, ele cobre todo o ciclo de vida do banco de dados, incluindo criação de tabelas, inserção de dados de teste, consultas e regras de negócio para usuários, eventos e lotes[cite: 5].
